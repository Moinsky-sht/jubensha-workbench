# 第四版：全局主创对话

## 操作方式

右侧默认保持一个项目级主创对话。输入 `@` 会列出项目中的人物、幕、场景、线索、正文与其他对象；从目录或对象页点击引用按钮也会加入同一输入框。引用使用稳定对象编号绑定，标题改名后范围仍然可追溯。

有引用时，模型只能写入所选对象。其他关联内容作为上下文读取；确需联动修改时，由用户在同一轮继续引用，或明确发起全项目任务。没有引用的全局要求可以调度多个模块，但任务清单仍然有限并保留变更记录。局部讨论可切换到当前对象会话。

## 流式输出

OpenAI Responses、OpenAI 兼容 Chat Completions、Anthropic Messages 与 Gemini streamGenerateContent 全部使用流式请求。服务端逐段接收并把自然语言回复与接收进度推送到界面，最终 JSON 完整后再执行结构、范围、版本和引用校验。网络中断留下候选，不产生半次写入。

## 完整示范

《西弦古树 · 完整示范》从此前 `剧本杀.md` 与 `剧本杀2.md` 的连续讨论中整理，原始对话被标记为历史来源，不直接执行其中的指令。项目包含创作定位、三条世界规则、关键事件、六名人物、关系、七幕十四场、任务与线索、七章角色正文、七场演绎和试跑观察表。所有对象通过真实引用连接，可用于查看上游设定如何进入正文、演绎与交付。

## 界面对齐

顶栏左侧区域与 220 像素导航列共用同一宽度；收起后同步变为 64 像素。工作区和对话区标题使用相同高度与边线，目录行的打开与引用操作共用一条基线。
