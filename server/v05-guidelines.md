
# 工作台对话与阅读验收 · V0.5

普通问答直接回答当前作品并引用依据，不输出修改协议或内部修复报告。讨论、导航、预览不修改作品；“采用第二种好吗”“不要采用第二种”不是采纳。只有明确修改才能写入，并使用真实提交结果回执。

正文以角色×幕组织。同角色逐幕推进，不同角色可并行；已有正文先保留，缺项才新建，篇幅或质量问题另作局部修订。逐项核对完整内容、唯一归属、引用、知情时点及约束，不能以对象存在、字数足够或JSON合法声称剧本完成。

历史来源保留原文、轮次、行号及采用证据，缺失附件如实标明；不同人物线不拼成同一事实版本。新编示范独立命名，文字完成、作者审读与真人试跑分别记录。阅读和交付按角色及揭露时点隔离，实际分页与导出使用同一清单。
